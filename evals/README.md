# Provider-neutral evaluation cases

Planned categories: English generation, Arabic generation, Egyptian Arabic, mixed Arabic/English, editing, advanced analytics, ambiguity, and unsupported requests. Run the same cases against every DashboardPlanner/LLMProvider adapter.

Per case capture schema validity, metric/dimension/filter/time/operation accuracy, unsupported metric hallucinations, edit accuracy, latency, and retries. Provider-specific cost, token, and GPU telemetry is optional. The first pass has contracts but no planner implementation; executable evals are scheduled after the mock planner.
