# Product vision

El-Dabbous customers describe an analytics question in English, Arabic, Egyptian business Arabic, or mixed language. The product maps the request to governed concepts, validates a dashboard specification, runs deterministic analytics, and renders interactive results. Customers can also start from a saved specification without an AI service.

Success means the same business request resolves to the same canonical metric and dimension IDs in both languages, while source systems and model providers remain replaceable.
