# Product vision

**Current:** El-Dabbous Analytics turns a governed semantic metric catalog into bilingual, market-aware dashboards. Users browse templates, create manually or through a structured planner, preview deterministic analytics, and explicitly save versioned dashboards. Personal folders/favorites organize accessible records. Themes affect presentation only.

The prototype demonstrates IQ and EG with synthetic facts. It does not connect to Odoo/customer data, authenticate production identities, convert currencies, generate SQL, persist automatically, or provide scheduled reporting/public links. Planned metrics remain discoverable but cannot execute.

**Next:** approve one real-data vertical slice against an agreed source report, tenant mapping, currency rule and privacy policy. Do not expand product scope while those P0 decisions are unresolved. [Readiness](../integration/production-readiness.md) and [questions for Malik](../integration/questions-for-malik.md) own the integration gate. [Stories](user-stories.md) define completed behavior; [scope](scope.md) retains the historical foundation scope.
